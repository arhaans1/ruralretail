# Packages the cleanup script will OFFER to remove.
# Format:  <package.name>  |  <SAFE or OPTIONAL>  |  <what it is>
#
# SAFE     = almost nobody needs it on a TV; removing it won't break anything.
# OPTIONAL = an app some people use. The script asks you about each one.
#
# Nothing is permanently deleted: apps are removed for the TV's user only
# ("pm uninstall --user 0"), so restore.sh or a factory reset brings them back.
#
# Deliberately NOT listed (removing these breaks the TV): the home screen/launcher,
# Google Play Services, Play Store, setup wizard, Google Assistant/voice search,
# remote-control services, system UI, input/HDMI and the settings app.
